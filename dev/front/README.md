# ProjectHub — React 18 Frontend Client

This directory houses the React 18 single-page application for **ProjectHub**, styled with **Material-UI v6** and routed via **React Router v7**.

## Tech Stack
- **React 18.3**
- **Material-UI v6** (`@mui/material`, `@mui/icons-material`, `@mui/x-date-pickers`)
- **React Router v7** (`react-router-dom`)
- **Axios** with JWT bearer interceptors
- **Date-fns** for date calculations

## Development Scripts
```bash
# Install dependencies
npm install

# Start local development server (http://localhost:3000)
npm start

# Build production bundle
npm run build
```

See the root [README.md](../../README.md) for full project architecture, backend configuration, and API specifications.
